# Fixed experiment protocol

Freeze this protocol before the first scored run. There is no tuning set.

- Generate 200 selectable entries across five topics: per topic, 12 entity observations, 24 same-entity metadata facts, three eligibility rules, one archive rule. Half the entities reach eligibility in one rule application and half in two. The goal and predicates are topic-specific. Shuffle entry IDs with seed 502 so ties cannot exploit generator order.
- Use five paired stream/tie seeds: 11, 23, 37, 47, 59. Each stream has five 40-question blocks. The first eight questions of each later block alternate old and new topics, starting with old. Draw entities from shuffled 12-item decks without replacement until a deck is exhausted. Each picker sees the same stream for a seed. Reset all state for each seed, budget and arm.
- Sweep K = 10, 20, 30, 40, 60, 80, 100. Define tight as the first two budgets (5% and 10%). Evaluate each falsifier separately at each tight budget by mean accuracy, not a significance test. Report all budgets and seeds.
- Give every arm the same randomly shuffled stable tie priority for a given seed. Random samples K without replacement each question using an independent seeded stream, with the same random draws across comparisons at a fixed seed and K.
- Harness score: count unique shared tokens between question (goal and subject) and entry (predicate(s) and subject where present). Tokens are case-folded underscore-delimited words. Add decayed recency bonuses of 0.5 for last successful use and 0.25 for last exposure, each halved for every additional question since the event. Blank history contributes zero. Keep seen and used timestamps separate.
- ECAN score: STI starts at zero. Before selection optionally add 0.25 STI per shared token. After reasoning every entry pays 15% of its balance, each winning proof entry earns 3 STI, co-used distinct entries increment both directed link weights by 1, then each entry with nonzero outgoing weight distributes 10% of its balance to its neighbors in proportion to those weights. All transfers use the same pre-diffusion snapshot. No-feedback disables wages and link learning only. Compare both variants with and without stimulus, using stimulus-on as the primary ECAN pair. No stimulus or wages use the answer key to rank entries before selection.
- The reasoner enumerates up to two unary forward applications over the selected entries only. If several proofs exist, use the shortest and then stable entry-ID order. Score exact derivability of the requested goal for the subject, with any successful proof fed back after selection. Verify each result against the planted unique proof in Python without using it to generate predictions.
- Report mean and sample standard deviation of seed-level accuracy, per-block accuracy, and wall runtime (picker and reasoner, excluding plotting and disk writes). No inferential claim from these synthetic streams.

## Addendum, 11/20

Freeze one setting for both line D arms before the scored sweep. Use the same KB, question streams, budgets, seeds and tie priority as the original six arms.

- `harness_ecan` (primary): before each question, use the plain harness scoring and tie-breaking function to rank all entries. As in the harness, exposure recency is based on the actual previous focus sets. Leave successful-use timestamps blank in both hybrid arms so that proof feedback enters only through the economy, not through stimulus. Add 0.25 STI to each of the top M ranked entries, with M = K. This uses one focus budget of nominations and the existing one-token stimulus amount. Do not also add per-token stimulus.
- Select exactly K entries by accumulated STI with the original tie priority. Follow the original ECAN schedule and parameters: after reasoning, charge rent, pay successful proof wages, update co-use weights and spread STI from a snapshot. The initial STI is zero as before.
- `harness_ecan_nofeedback`: same stimulus, exposure bookkeeping, selection and rent, but ignore proofs. No wages or co-use updates occur, so there are no links for spread.
- Compare mean accuracy at every K against the plain harness and against the matched no-feedback arm. Report both hybrids in the accuracy and K = 10 drift charts. Check whether first-question stimulus makes the zero-initialized focus query-dependent and distinguish that from solving proof acquisition or later drift.
