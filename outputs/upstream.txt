iCog: what the code does
=======================
- Attention value is (STI, LTI, VLTI), distinct from truth value (STV). The bank computes wage as base × (1 + clamp((funds − target)/buffer, −1, 1)); stimulate multiplies STI/LTI wages by stimulus and calls setAv. setAv stores the AV and importance bin, preserves existing STV, credits old-minus-new STI/LTI to the respective funds, and updates AF. AF updates existing entries, fills capacity, or evicts a minimum-STI entry if the newcomer has strictly higher STI. Maximum AF size is a capacity, not the inference-step budget.

- The library imports bank, rent, AF/WA diffusion, Hebbian creation/updating and forgetting modules. The generic runner hyperposes the Hebbian, diffusion and rent calls with forgetting commented out. AF diffusion selects sources by STI (TOPK fraction of AF) and trades along incident and Hebbian connections. AF rent is wall-clock gated and caps deductions at current holdings; use a deterministic tick if adapting this for a paired experiment.

CAIRN: baseline design from code
================================
1. Unpriced steering (the direct comparison for budgeted reasoning). All three arms use the same query, same PLN API and same inference-step argument B (default 10; driver also accepts budget grids and a seed, default 0). The arm changes the premise set, not B:
   - weighted: all stamped premises, with their existing truth values; no AF gate. Despite the name, the steering code does not STI-rank or truncate this premise list. This is a full-KB-at-equal-B baseline, not an unbounded proof run or a static top-k harness rule.
   - influenced: pass a table only if at least one leg belongs to BOTH query objects Q and real focus F: legs(table) ∩ Q ∩ F ≠ ∅. Separate legs matching Q and F do not suffice. This is a hard membership filter, not soft ranking within PLN. In fixed scenarios, CAIRN builds incident edges from table legs, registers atoms, stimulates scenario seed atoms, runs configured ECAN cycles, and takes positive-STI AF as F. CAIRN's cycle is explicitly sequenced (AF rent/diffusion, WA rent/diffusion, Hebbian creation/update, forgetting), not iCog's generic hyperposed runner. Example fixtures: Roman A→D with four premises and a WordNet slice Ant→Insect with eight.
   - distracted: replace F with seeded random S from the scenario pool (without replacement over pool entries; size min(|F|, pool size)); apply the exact same Q-and-focus gate. The regular sampler does not exclude query atoms or force S disjoint from F. Matching focus size does not match admitted premise counts; if Q ∩ S is empty the arm can have no premises, in which case the wrapper returns an empty answer without calling PLN.
   Outputs include solved, confidence (0 on empty answer), answer/evidence, admitted premise count and wall time per arm, plus focus, seed and query–AF overlap. The timer excludes premise filtering. CAIRN 'solved' means the answer has the expected truth-value/evidence pair shape, not a separate ground-truth check.

2. Snapshot and feedback variants. B2 uses end-of-run snapshots; B3 uses mid-run CIP snapshots, with offline cap × B replay available. Freeze-F does not rerun ECAN; its normal scenario builder takes highest-STI saved AF entries up to the cap and can force query atoms into focus. Re-dynamics seeds and cycles again in a reconstructed graph. Snapshot-generated node STV priors also derive from STI and are shared across steering arms, so weighted is not necessarily independent of upstream ECAN on snapshot inputs. Standalone feedback uses an influenced proof's evidence stamps to identify premise endpoint atoms, zeros each AV then stimulates it, runs one ECAN cycle, and reports before/after STI and AF. Live B4 adds the wage at the CIP probe hook only on a solved influenced query; it prefers proof stamps mapped back to original atoms, with query/attention fallbacks. Open-loop live probes do not apply those wages. Neither freeze-F nor the weighted arm alone is a matched, live no-feedback ablation.

3. Optional linkage pricing at this CAIRN revision is a separate protocol, not the three unpriced arms above. The live influenced account uses AF candidates, query atoms first, then descending STI. It buys new atoms at nonnegative STI, retains owned atoms without paying again (subject to release mode), and carries state between periods. An open priced pass can admit an unaffordable tail for free up to k, whereas closed mode stops at the fund bound, so toggling closed-loop in this path changes more than feedback. Offline priced controls start each period from the live opening credit without carrying their own balances: weighted orders the importable bank with query priority, and distracted draws up to the live held count with seed 0 excluding query objects. Do not confuse these with ordinary steering's full KB and full-pool random arm.

Implication for this project: keep tasks, premise bank and base truth values, reasoner, and B fixed across arms; report actual admitted premise counts alongside AF size and outcomes. Define the static harness rule explicitly (CAIRN's full-KB weighted arm is not that rule). For a matched no-feedback control, use the same ECAN initialization, inputs, dynamics and budget, suppress only proof-contingent updates, and let both trajectories continue. If equal premise count is needed to separate ranking quality from pruning, match it directly rather than assuming equal |F| implies it. Predeclare seeds and any use of query objects in admission. These are recommendations, not upstream results.
